# Release license materials

These files are bundled in Contents/Resources/Licenses and displayed by the About box's Licenses button. ThirdPartyNotices.txt preserves cached dependency notices from the locked macOS Cargo graph (including build-time and conditional dependencies). Supplemental licenses for crates that omit license files from their package are copied from the upstream revisions recorded in their .cargo_vcs_info.json. Map-terms.txt reproduces the bundled map collection's separate terms.

Before public distribution, add the public repository URL and exact release tag to ThirdPartyNotices.txt and provide complete corresponding buildable source. Bundling notices alone does not satisfy LGPL source/relinking requirements or establish permissions for artwork. Update dependency notices whenever the dependency lockfile changes.
